# Portfolio evidence

This repository is the public recruiter portfolio. Each product page below is evidence: recordings, architecture, and measured results. Application source is private and is not included. Nothing on these pages is an installer, a source archive, or a request to clone or build an application.

FlexEd Academy stays at the root of this repository. Its pages and media paths are unchanged. The live product at [flexedacademy.com](https://flexedacademy.com) remains available for subscribers. This portfolio does not change billing, accounts, or deployment.

The [project inventory](./inventory.md) lists the other resume-linked work and where its public evidence lives today.
